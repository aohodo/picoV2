# Changelog

## 0.2.0 - 2026-09-26

- Reworked Pico into a human-inspired, evidence-driven coding Runtime.
- Added transactional Shadow workspaces, delivery review, verification identity, and safe commit semantics.
- Added bounded native-provider recovery, adaptive context projection, durable/session memory separation, and resume handling.
- Added Python/Java repository navigation with optional LSP enrichment.
- Added obligation-driven work focus, failure-prioritized feedback, cross-platform execution profiles, and progress reporting.
- Added Windows/Linux CI and reproducible Harness, context, memory, and recovery evaluation artifacts.
- Added a comparable real-repository run report for repeated V1/V2 evaluations.

The Runtime is intended for human-decomposed, independently verifiable coding work units. It
does not claim unattended whole-product development or hostile-process isolation.
